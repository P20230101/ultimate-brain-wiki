## 二、研究范围与固定约定

- 资料范围包括原始 JPG/DAT、Press/Pos 等 XLS/XLSX、论文、实验记录、几何图纸及已有 MatchID 配置和输出；既有材料盘点、数据处理和论文笔记继续作为项目组成部分。
- 正式图像来源为旋转后的 vertical_all_45°/PAPER。照片按同名 JPG+DAT 配对；稀疏或缺失帧如实登记，不补帧。受力起点、峰值、终点/断裂点必须有力记录或清楚标记为无法确定。
- Press 按力处理，工程单位 N 已由用户确认。所有双轴实验均为等双轴；不存在 1:0.5、1:0 等非等双轴路径，也不得将其列作阻塞。默认同步力 X=(X1_Press+X2_Press)/2、Y=(Y1_Press+Y2_Press)/2；用户确认外围夹持路径中的机器力可直接作为 ROI 边界合力输入 MatchID 自带 VFM。拉伸正值输出，首行归零；单轴非加载方向按配置处理。
- 相机设置频率、由帧号和实验时间推算的有效采样频率、硬件触发频率必须区分。没有时间戳或触发证据时，不把推算值写成硬件实测值。
- 试样几何分为外围夹持/加载结构和中心减薄分析区：外围整体厚度记录为 3 mm，中心 ROI 厚度为 1 mm，二者并存且不能互换。ROI 是中心区内截取的虚拟分析区域，必须完全落在 1 mm 减薄区内、不跨越厚度变化边界；MatchID 工程对中心 ROI 使用 1 mm。机器力传感器在外围夹持/加载路径上，用户确认其力可作为 ROI 边界合力。中心有效宽度和标距当前工作口径为 30 mm；ROI 约 28×28 mm。臂宽约 30 mm、每臂 7 条狭缝、狭缝长约 40 mm、臂根圆角约 R3 mm、狭缝端距中心约 0.2 mm 等结构信息须分别链接其论文/图纸来源，区分设计值、推定值和实测值。
- 机器力传感器位于外围四周夹持/加载路径上；用户确认机器力可直接作为 MatchID 自带 VFM 中 ROI 边界所需合力输入。当前工作遵循 MatchID 自带 VFM 的边界/合力定义，不自行恢复 ROI 四边牵引分布、不假设均布边界应力、不另行重建完整边界载荷算法。
- 原始机器右上/左下加载头为 Y1/Y2，右下/左上为 X1/X2；旋转后 DIC 坐标中的 ROI 顶部/底部对应 X2/X1，左侧/右侧对应 Y2/Y1。X/Y 方向必须与旋转后的 DIC 坐标和传感器方向核对；MatchID Boundary 顺序记录为 0 顶、1 左、2 右、3 底。基准 VFM 使用 MatchID 自带求解器；不恢复四边牵引分布、不额外假设均布边界应力、不另建完整边界载荷算法。
- 当前全部双轴实验均为等双轴加载；没有 1:0.5、1:0 或其他非等双轴路径。不得将缺少非等双轴数据列作当前项目阻塞。
- 论文或 Abaqus 示例中的 E、ν、屈服和硬化参数是文献/仿真参考值，不是本实验识别值。正式识别值必须有对应实验、模型、区间和不确定性。

## 三、总体数据流

原始只读资料 → 映射与质量审计 → 有效帧和终点确认 → DIC 全场与同一时间轴 X/Y 力 → 单轴弹塑性 VFM → 跨单轴验证 → 双轴 VFM → 实验—模型一致性和参数稳定性 → 人工复核 → GitHub 发布。

每一步的输入、方法、结果、失败项、不确定性和下一步写入 Obsidian，并更新 index.md 与 log.md。

### Linear 公式与参数符号核验门槛

项目试样优化论文第 2.3.2 节将模型称为“等向线性硬化”，但式 (2.19) 原页写为 `σ_y=σ_y0−H ε̄p`；同一论文参数页列 `σ_y0=21 MPa`、`H=+180 MPa`。若按公式字面使用正 `H`，屈服应力随等效塑性应变下降，线性外推约在 `ε̄p=21/180≈0.1167` 时降至零。这是软化响应，与“线性硬化”文字不一致。

这不授权把负号直接改成正号：Abaqus 官方定义允许等向塑性屈服应力作为等效塑性应变的函数增加或降低，因此它可能是有意软化，也可能是论文公式/符号错误。当前可查的六份 PA12 几何扫描 `.inp` 只有 `PA12_PROVISIONAL` 弹性材料卡，没有 `*Plastic` 表，不能证明论文实际求解时输入了哪一种塑性曲线。

在实现 Linear 模型、解释 MatchID 的 `H`、为参数扫描定义 `H` 符号，或将 S16 的 `H=41.55 MPa` 作为材料参数前，必须核对原始 Abaqus `*Plastic` 材料卡或向作者确认式 (2.19)，并核实 MatchID 当前模型的硬化方程与参数定义。此前的 `E=1800 MPa、ν=0.375、Y₀=21 MPa、H=180 MPa` 仍仅是试样优化仿真工作值，不是本实验识别结果。

证据：`D:\C盘迁移\Desktop\yuan\3D打印尼龙材料的双轴拉伸测试方法与力学性能(1).pdf` 第 2.3.2 节，印刷第 11–12 页（MinerU：`doc:b39265e/tier:standard/page:19`–`page:20`）；Abaqus 官方[经典金属塑性说明](https://docs.software.vt.edu/abaqusv2025/English/SIMACAEMATRefMap/simamat-c-metalplastic.htm)说明等向塑性屈服应力可随塑性应变增加或降低，并按“屈服应力—等效塑性应变”表格定义。

在已明确目标模型实现并评估后，可继续纳入有可靠公式来源、与 PA12 数据相容且参数可辨识的其他弹塑性模型。超弹性、蠕变等不同材料行为不得混称为弹塑性硬化模型；速率效应若由跨速率试验显示为实质问题，再单独建模和验证。

对每个模型，使用相同数据和 MatchID 合力输入定义，记录识别参数、参数敏感性/相关性、残差、全场或载荷预测误差、不同初值和帧区间下的稳定性，以及适用应变、方向和速率。不能仅按单一拟合分数选模，也不能将不可辨识的参数包装成已识别结果。

## 八、方案决策与复盘

- 决策：依次完成数据准入、边界/本构定义、单轴识别、跨单轴验证、双轴扩展、稳定性和人工复核。
- 决策：先实现截图模型清单中的硬化模型，所有模型用统一数据和边界假设比较。
- 决策：论文仿真参数仅作初值或对照，不作为实验识别结果。
- 决策：Linear 公式及 H 符号必须先由原始 Abaqus 塑性材料卡/作者资料与 MatchID 当前模型定义核实；未解开前保留为前置待验证，不改公式、不推定 H 方向。
- 决策：MatchID 自带 VFM 是基准；用户确认机器力可直接作为 ROI 边界合力。边界方向、ROI 位置/尺寸、厚度、逐帧同步及识别检查仍须逐项通过。
- 决策：所有双轴均等双轴；按 0.2、2、20 mm/s 分别拟合。阶段1固定 ν=0.375 识别 E；阶段2固定该 E 和 ν=0.375 识别 Y、H。
- 待记录：各阶段完成后补充实际输入、选型理由、模型误差、不确定性、失败原因和经验复盘。

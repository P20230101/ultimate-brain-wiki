# LLM Wiki 模式

## 定义

LLM Wiki 模式是一种由 LLM 持续维护的 Markdown 知识库模式。它把知识系统分为三层：原始资料、编译后的 wiki、以及约束维护行为的 schema。

## 三层关系

| 层级 | 责任 | 是否由 LLM 修改 |
| --- | --- | --- |
| Raw sources | 保存事实来源和原始材料 | 否 |
| The wiki | 保存摘要、概念、实体、方法、综合分析和交叉引用 | 是 |
| The schema | 规定目录、页面字段、流程和更新规则 | 是，但需谨慎 |

## 与传统 RAG 的差异

传统 RAG 在查询时检索原文片段，并临时组合答案。LLM Wiki 则把资料预先编译成长期存在的知识页。新资料进入时，LLM 会更新已有页面、指出冲突、补充链接，让知识库随着使用变得更完整。

## 适用场景

- 长期研究一个主题。
- 维护实验、数据和工程决策记录。
- 把阅读、剪藏、论文和项目资料沉淀为可复用知识。
- 需要人机共同维护的个人或团队知识库。

## 边界

LLM Wiki 不是原始资料的替代品。重要结论仍要能回溯到 `raw/` 中的来源。对需要精确复现的实验和数据处理，wiki 负责组织结论，原始数据和脚本仍应保留在来源层或项目仓库中。

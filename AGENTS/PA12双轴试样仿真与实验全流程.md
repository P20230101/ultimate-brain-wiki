## 1. 研究目标

在真实打印和双轴加载实验之前，使用 Abaqus 比较不同双轴试样设计，使中心双轴加载区的应力、应变场尽可能均匀，并以 MatchID DIC、同步力值和 VFM 结果进行独立验证。

当前研究对象为 SLS 打印 PA12：

## 4. 材料与坐标标定

正式模型采用正交各向异性弹性参数：

```text
E1=E_X, E2=E_Y, E3=E_Z
nu12, nu13, nu23
G12, G13, G23
```

其中 `E_X/E_Y` 应由面内单轴数据标定，`E_Z` 应由 Z 向数据标定；剪切模量和泊松比不能从当前文件名推定。力值单位、试样有效截面和工程应变定义必须从实验机配置、试样尺寸和 DIC 标定共同确认后，才能进入正式材料卡。

材料卡的状态分为：

1. **待标定**：当前状态。不能提交正式仿真结论。
2. **流程临时值**：只用于验证 STEP 导入、网格、边界、作业提交和 ODB 后处理链路；结果不得用于论文。
3. **已标定**：由独立试验组拟合并用留出试验复核后，才可用于设计筛选。

## 5. Abaqus 模型约定

### 5.1 建模对象

- 三维实体模型，导入每个 STEP。
- 单位制：`mm-N-s-MPa`；若实际力值不是 N，必须在材料和载荷登记中改写单位制。
- 初始网格使用四面体二次单元 `C3D10`，因为当前 STEP 含有狭缝和厚度过渡，先保证复杂几何可网格化，再做网格收敛。
- 初始种子尺寸为 `1.0 mm`，只作为流程验证值；正式结果至少比较三个网格尺度。
- 材料方向默认与全局 `X/Y/Z` 重合，并在输出报告中记录。

### 5.2 边界与加载

四个臂端面分别建立参考点和运动耦合：

- `XMIN`：固定 `U1/U2/U3`，作为平移和出平面刚体运动约束。
- `YMIN`：固定 `U2`，提供 Y 向反力基准。
- `XMAX`：施加 `U1=ΔX`。
- `YMAX`：施加 `U2=ΔY`。

`ΔX/ΔY` 必须由目标双轴应变或实验位移同步策略给定；不能从样本名直接推断。四臂耦合面、约束自由度和位移值在每个作业的 JSON 清单中保存。

### 5.3 中心区定义

主评价区为中心平坦区 `28 × 28 mm`，位于试样中面投影范围内。仿真后处理在该区域统计 `S11/S22` 与 `E11/E22` 的均值、标准差、变异系数和空间梯度；过渡圆角与狭缝端部不纳入主均匀性区，但单独检查峰值和应力集中。

## 6. 筛选指标

对每个设计、每个加载状态和每个网格记录：

```text
CV_E11 = std(E11) / abs(mean(E11))
CV_E22 = std(E22) / abs(mean(E22))
CV_S11 = std(S11) / abs(mean(S11))
CV_S22 = std(S22) / abs(mean(S22))
K_ratio = abs(mean(E11) - mean(E22)) / (abs(mean(E11)) + abs(mean(E22)))
G_transition = max(abs(field_transition)) / max(abs(field_center))
```

初筛主指标为四个中心区变异系数的和；`K_ratio` 检查双轴平衡，`G_transition` 检查减薄过渡和狭缝端部是否出现不可接受的局部集中。指标只用于同一材料、同一边界和同一载荷定义下的相对比较。

正式采用前固定以下门禁：

1. STEP 为单一有效实体，包围盒与登记值一致。
2. 作业能完成且无未处理的网格、接触、约束或收敛错误。
3. 网格加密后主指标变化不超过预先登记的阈值；当前建议门槛为 5%，需在正式筛选前固定。
4. 最优设计在至少一个未参与筛选的加载状态下仍保持排名靠前。
5. 仿真中心区趋势与 DIC/VFM 的均值、梯度和方向性一致；若不一致，回到材料卡、边界条件和同步记录，不直接调整结论。

## 7. 实验闭环

1. 先用单轴 X、单轴 Y 和 Z 向数据标定材料方向参数。
2. 用五个中心厚度模型运行第一轮几何筛选。
3. 对排名靠前的模型检查网格、边界和加载比敏感性。
4. 打印候选模型，记录 SLS 打印面方向和逐层 Z 方向。
5. 使用 MatchID DIC，保持参考图、ROI、标定比例和坐标轴定义一致。
6. 用已同步的力值和 DIC 帧执行 VFM；XY-0.1-02 当前已有 258 帧力值匹配报告，可作为同步流程样例。
7. 以未参与筛选的实验状态验证仿真排序，形成最终设计结论。

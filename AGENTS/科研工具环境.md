# 科研工具环境

本文件记录论文阅读、解析和文献检索所依赖的本机工具。密钥只保存在 Windows 用户级环境变量和对应工具的本机配置中，不写入 Second Brain 或 Git 仓库。

## MinerU

- 来源：`opendatalab/MinerU` 的 `mineru` skill。
- Agent skill：`C:/Users/Administrator/.agents/skills/mineru/SKILL.md`。
- MinerU 版本：`4.0.5`。
- Python：`3.12.10`。
- 标准模型：已下载并校验。
- 默认路径：通过 MinerU 远程解析服务使用标准解析质量。
- 远程端点：`https://mineru.net/api`。
- 远程配置变量：`MINERU_API_KEY`。
- `paper-analyzer` 兼容变量：`MINERU_TOKEN`、`MINERU_API_TOKEN`。
- 验证方式：`mineru usage --json` 返回账户用量和限制信息。

常用命令：

```powershell
mineru version --json
mineru server start
mineru server status --json
mineru parse "论文.pdf" --json
mineru usage --json
```

MinerU 默认遵守本地优先和隐私边界。使用远程解析时，必须明确指定远程路径或由用户授权的工作流调用远程服务。

## Semantic Scholar

- API 端点：`https://api.semanticscholar.org/graph/v1`。
- 用户级环境变量：`S2_API_KEY`、`SEMANTIC_SCHOLAR_API_KEY`。
- 请求认证头：`x-api-key`。
- 验证方式：论文搜索接口返回 `HTTP 200` 和论文元数据。

示例请求：

```powershell
$headers = @{ "x-api-key" = $env:S2_API_KEY }
Invoke-RestMethod `
  -Uri "https://api.semanticscholar.org/graph/v1/paper/search?query=machine%20learning&limit=1&fields=title,year" `
  -Headers $headers
```

## 生效方式

API key 使用 Windows 用户级环境变量保存。重启 Codex 或新建终端后，Agent 和脚本才能自动读取最新变量；当前会话中需要显式从用户环境加载变量后再运行脚本。

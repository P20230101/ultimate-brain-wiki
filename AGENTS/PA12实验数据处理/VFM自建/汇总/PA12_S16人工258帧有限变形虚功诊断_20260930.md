# S16 等双轴 258 帧有限变形虚功诊断

## 结论

S16 的 258 帧人工映射可复现，照片、时间及 X/Y 力与人工索引逐行一致；全 Job ROI 的 DIC 覆盖率为 **89.2248%**，低于项目 95% 主域门槛。因此本次结果仅用于诊断，不放行材料参数，也不进入 J2 的 Y/H 识别。

## 输入与帧索引

- 试验：`S16_XY_0.2`，等双轴。
- 人工确认的有效序列：`000000.jpg`–`000257.jpg`，共 258 帧。
- 原始目录计数：259 张 JPG、258 个 DAT；`000258.jpg` 无同名 DAT，且不在本次人工映射内。
- 全程共同 DIC 网格：每帧 10,098 点；参考位移场来自 `000000.jpg.dat`。
- 索引复核：输出 CSV 与人工映射均为 258 行；照片顺序、时间、X 向力和 Y 向力逐行相同（数值容差 `1e-8`）。参考帧直接使用已加载的参考 DAT 场；其余帧继续使用现有 MatchID 合并场量文件。

## 虚功诊断

| 指标 | 结果 |
| --- | ---: |
| 完整 Job ROI 面积 | 759.324103 mm² |
| DIC 支持交叠面积 | 677.505105 mm² |
| 全 ROI DIC 覆盖率 | 89.2248% |
| 固定 `ν=0.375` 的条件 `E` | 3498.487479 MPa |
| 拟合窗口残差 RMS | 31.350824 N |
| 全历程残差 RMS | 4945.965894 N |
| 力 RMS | 362.297322 N |
| 相对 RMS | 8.653% |
| 自由 `ν` 的 1% 残差带 | 0.27059–0.499 |

全 ROI 虚功资格状态为 `BLOCKED_INCOMPLETE_DIC_SUPPORT`。内功只由部分 DIC 支持域积分，不能与完整 ROI 的机器合力宣称平衡。DIC subset 内缩域覆盖率为 97.69%，仅作敏感性分析，不能替代完整 Job ROI。自由 `ν` 的剖面较宽，当前数据不能有效确定 `ν`；表中的 `E` 是给定虚场、固定 `ν` 和当前部分支持域下的条件诊断值，不是 PA12 材料参数。

## 尚未闭合的资格

- 人工时间索引已逐行复现，但硬件触发时间及相机—力通道的物理同步仍未验证。
- Press 通道按项目约定作为力、数值以 N 表示；传感器单位/标定证据尚未闭合。
- 配置采用中心厚度 1 mm；实际厚度区域到 DIC/Job ROI 的注册仍需独立几何证据。
- 部分 DIC 支持域与完整边界外功的等价性未成立。
- 当前本构是虚功诊断用线性有限变形近似，不是经验证的 PA12 有限应变塑性模型。

# Raw sources

这里保存原始资料。原始资料是 wiki 的事实来源，默认不可改写。

## 放置规则

- 文章、网页剪藏、论文、访谈、笔记原文放在 `raw/`。
- 图片、PDF 附件和数据文件可放在 `raw/assets/` 或按主题新建子目录。
- 文件名使用可读中文或英文，避免只用日期编号。
- 若资料被修订，新增文件保存修订版，不覆盖旧版。

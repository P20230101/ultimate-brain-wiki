# PA12 照片—力数据同步实现计划

## 成功标准

- 单元测试覆盖事件检测、同一照片时间轴插值、零点校正和 VFM 行数门禁。
- 当前样例能读取 `.xls` OOXML 状态文件，自动给出加载起点、峰值和断裂掉载点。
- 输出目录位于 `second brain/Agents/PA12实验数据处理`，原始 JPG、DAT、XLS 不发生内容变化。
- 正式 VFM 文件只有在照片、X、Y 数量完全相等时生成。
- 检查图、中文概览表、中文照片—力表和处理报告可独立查看。

## 步骤

1. 新增 `tests/test_pa12_sync.py`，先写失败测试：
   - 负向加载曲线的事件点检测；
   - 同向 Press 通道平均；
   - 力时间到照片时间的线性插值和首值归零；
   - 259 帧样例按 10 Hz 选择有效区间；
   - 数量不一致时阻止正式 VFM。
2. 新增 `tools/pa12_sync.py`：
   - JSON 配置解析；
   - JPG/DAT 配对与编号检查；
   - XLS/XLSX 读取；
   - 基线、加载、峰值、掉载检测；
   - 同一照片时间轴的 X/Y 插值；
   - CSV、Markdown、PNG 输出。
3. 新增当前样例 JSON 配置，路径指向原始数据，输出指向 Vault。
4. 运行单元测试并修正逻辑。
5. 在临时输出目录运行样例，核对事件点、数量、首值、NaN、单调性和通道同步。
6. 将验证后的样例结果写入 Vault，并更新当前 Wiki 的已确认信息、索引和日志。

## 取舍

- 采用 CLI + JSON，不先做 GUI；这样人工修改仍可复现，且后续批处理无需重写逻辑。
- 默认使用两路同向通道平均值，而不是只取一路；在等双轴假设下代表值相同，同时能在报告中暴露通道不一致。
- 默认保留校正后的原始符号；需要取力值大小时通过 `force_sign` 明确设置，避免静默改变物理符号。

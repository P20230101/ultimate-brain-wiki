# PA12 照片—力数据同步与 VFM 生成

## 目标

为 PA12 单轴/双轴拉伸实验建立可重复的命令行处理流程。当前先验证一组 `XY-0.1-02` 样例，后续通过 JSON 配置复用到其他试验。

输入包括 DIC JPG/DAT、控制器状态 XLS/XLSX、加载速度和相机设置频率。输出只写入用户指定的 Obsidian Vault，不修改任何原始文件。

## 已确认的实验约定

- `Press` 工作表中的 `X1_Press`、`X2_Press` 是 X 向力通道；`Y1_Press`、`Y2_Press` 是 Y 向力通道。
- 当前默认按等双轴处理：X 向代表力为两路 X 通道平均值，Y 向代表力为两路 Y 通道平均值。两路差异只作检查并写入处理报告。
- 零点按正式加载前基线平均值计算：`F_corrected = F_raw - F_baseline`。默认不改变力的正负号；符号通过配置项显式控制。
- X/Y 必须使用完全相同的照片时间轴，并分别对同一时间轴插值。
- 有可靠 JPG EXIF 拍摄时间时优先使用其时间差建立照片时间轴；没有可靠时间时，按检测到的加载起点和断裂点均匀建立；实际照片频率用 `(照片数量 - 1) / 有效实验时间` 计算。
- 若存在 `Pos` 工作表中的设备位移列，优先用其在有效区间内的实际位移；否则用速度定义计算照片位移。

## 自动检测

1. 读取 `Press` 工作表，检查 `T` 严格递增并计算力采样频率。
2. 用初始基线窗口估计 X/Y 零点，并以基线中心线的偏离幅值寻找持续加载起点。
3. 在加载起点之后寻找力幅值峰值。
4. 在峰值之后寻找持续掉载到峰值比例阈值以下的第一个位置，作为断裂/掉载点。
5. 如果用户在 JSON 中提供图像帧号或力索引，则使用人工覆盖，并在报告中标记为人工覆盖。

检测仅负责给出可复现的候选点；检查图和报告必须明确显示起点、峰值、断裂点以及最终有效区间。

## 无时间戳时的照片选择

默认把文件夹中的首个连续帧编号作为相机时间轴零点，用相机设置频率估计候选帧号：

- 起始帧：距离加载起点最近的帧；
- 结束帧：距离断裂点最近的帧；
- 最终时间轴：在选定首尾帧之间，将有效实验时间均匀分配给所有照片。

若选定区间内或原始集合存在 JPG/DAT 不成对、缺号或重复，报告问题并禁止正式 VFM 输出；不通过删除数据来强行凑数量。

## 输出

输出根目录为：

`D:/C盘迁移/Desktop/yuan/second brain/Agents/PA12实验数据处理`

每次运行写入：

- `实验概览/<实验编号>_实验概览.csv`
- `照片力匹配/<实验编号>_照片-力对应表.csv`
- `VFM专用力值/X方向/X-速度-照片数量.csv`
- `VFM专用力值/Y方向/Y-速度-照片数量.csv`
- `检查图/<实验编号>_检查图.png`
- `处理记录/<实验编号>_处理报告.md`

用户表格只包含用户要求的字段；路径、内部索引和调试字段只出现在处理报告中。

正式 VFM 文件写出前必须满足：

`照片数量 == X CSV 行数 == Y CSV 行数`

不满足时只写匹配表、检查图和报告，不写正式 VFM CSV。

## 当前样例配置

- 实验编号：`XY-0.1-02`
- 力文件：`xy-2-0.1_state_20250529104919_20250529104947.xls`
- 相机设置频率：10 Hz
- 加载速度：0.1 mm/s
- 速度定义：单方向速度
- 力表：`Press`
- 位移表：`Pos`

## 非目标

- 本阶段不读取或修改 DIC DAT 内的应变结果。
- 本阶段不做应力—应变计算、VFM 识别或材料参数拟合。
- 不把历史分析目录中的 CSV 当作当前实验的计算答案。

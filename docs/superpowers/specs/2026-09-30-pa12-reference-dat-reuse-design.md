# S16 人工 258 帧索引的参考 DAT 复用设计

## 目标

让 S16 等双轴诊断使用用户确认的 258 帧人工映射（`000000.jpg`–`000257.jpg`），并复用已经读取的 `000000.jpg.dat` 参考场。原始照片、DAT、力数据和人工映射文件保持不变。

## 当前输入衔接

S16 人工映射表保留列名 `时间_s`、`X向力_N`、`Y向力_N`；现有 VFM 索引读取器使用 `时间/s`、`X向力/N`、`Y向力/N`。此外，现有 MatchID 合并场从 `000001` 开始，不含参考帧 `000000`。若逐行都从合并目录读取，258 帧索引会在参考帧处失败，或不得不额外制作重复的参考场文件。

## 设计决定

1. 在索引读取边界将三组已知列名映射为现有规范列名：
   - `时间_s` → `时间/s`
   - `X向力_N` → `X向力/N`
   - `Y向力_N` → `Y向力/N`

   `照片`、行顺序及数据值不变；不改写人工映射源文件。
2. S16 有限变形诊断配置改用 258 帧人工索引，并把 `000000.jpg` 指定为参考照片、对应原始 DAT 指定为参考场来源。
3. 诊断器构造当前帧序列时，索引行照片等于参考照片时直接复用已读取的参考场；其他照片继续读取现有 MatchID 合并场。共同点对齐、时间/力取值、虚功计算和资格门槛均不变。
4. S16 新诊断写入独立的 258 帧结果目录，避免覆盖旧 257 帧诊断；旧结果只作为历史对照，不再作为当前配对样本入口。

## 数据流

```text
S16 人工 258 帧索引 ──列名规范化（仅内存）──┐
                                             ├─按照片顺序组成 258 帧诊断
000000.jpg.dat ──读取一次，复用为参考/首帧 ─┤
000001–000257 MatchID 合并场 ───────────────┘
```

不把 VFM3 导出场混入 MatchID 合并场，不生成复制的 `000000` 合并 CSV，也不改动任何原始数据。

## 验收条件

- 单元测试确认三列别名读取后映射值、照片名和行顺序不变。
- 集成回归中，索引含参考照片而合并目录没有该照片 CSV 时仍可完成序列构造；参考照片使用已加载参考 DAT 场，其他帧仍从合并目录读取。
- S16 实际诊断报告包含 258 帧，首末照片分别为 `000000.jpg` 与 `000257.jpg`，时间与 X/Y 力逐行来自同一人工索引。
- 共同 DIC 点不足等既有输入错误仍按原行为报错；不做静默替代。

## 范围外

不改 S19 128 帧主样本，不重算或修订力基线、时间映射、坐标方向、厚度、ROI 覆盖门槛或本构模型；不运行 J2 参数识别，不将诊断结果作为正式材料参数或 VFM 放行结论。
